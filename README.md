# Gihozo - Doctor Co-Pilot API

**Gihozo** is a lightweight API designed to assist medical professionals by analyzing, summarizing, and interpreting patient cases using the BioMistral-7B model.

---

## 🚀 Quick Start

1. **Install dependencies**

```bash
pip install -r requirements.txt

```

2. **Run the API**

```bash
python api_server.py

```
